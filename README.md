# Sabbath Spa Management System

Sabbath Spa Management System is a dedicated yet elegant operations hub designed for Sabbath Spa & Wellness Hub. It streamlines bookings, client records, and waiver management in a calm, premium digital environment.

## Tech Stack

- ** Framework:** Next.js 14 (App Router)
- ** Language:** TypeScript
- ** Styling:** Tailwind CSS 4 (branded tokens)
- ** Database:** Supabase (PostgreSQL)
- ** Authentication:** Supabase Auth

## Setup Instructions

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Environment Variables:**
   Copy `.env.example` to `.env.local` and add your Supabase credentials.
   ```
   NEXT_PUBLIc_SUPABASE_URL=your-project-url
   NEXT_PUBLIc_SUPABASE_ANON_KEY=your-anon-key
   ```
